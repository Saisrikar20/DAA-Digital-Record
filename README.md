## 📑 Detailed Experiment Breakdown

### Module 1: Empirical Analysis & The Counter Method (Step-Count)

The **Counter Method** measures the exact computational work performed by an algorithm by embedding increments (`count++`) at every basic instruction, condition check, and loop body.

#### 1. While-Loop Accumulator Complexity
* **Objective:** Determine the exact step count for $i \leftarrow 1, s \leftarrow 1$; while $s \le n$: $i \leftarrow i + 1, s \leftarrow s + i$.
* **Analytical Derivation:** Since $s$ grows as the triangular sum $T_k = \frac{k(k+1)}{2}$, the loop terminates when $k \approx \sqrt{2n}$.
* **Asymptotic Bound:** $\mathcal{O}(\sqrt{n})$ time, $\mathcal{O}(1)$ auxiliary space.
* **Sample Test:** Input: `9` $\rightarrow$ Count: `12` | Input: `4` $\rightarrow$ Count: `9`.

#### 2. Nested Conditionals with Break Statement
* **Objective:** Find step count for an inner loop $j=1 \dots n$ that executes twice and immediately breaks.
* **Asymptotic Bound:** $\mathcal{O}(n)$ time, $\mathcal{O}(1)$ auxiliary space.
* **Sample Test:** Input: `2` $\rightarrow$ Count: `12` | Input: `1000` $\rightarrow$ Count: `5002` | Input: `143` $\rightarrow$ Count: `717`.

#### 3. Factorization / Divisor Counter
* **Objective:** Empirical step-count for exhaustive divisor search: $\forall i \in [1, num]$, testing $(num \pmod i == 0)$.
* **Asymptotic Bound:** $\mathcal{O}(n)$ time, $\mathcal{O}(1)$ auxiliary space.
* **Sample Test:** Input: `12` $\rightarrow$ Count: `31` | Input: `25` $\rightarrow$ Count: `54`.

#### 4. Multi-Nested Logarithmic Loops
* **Objective:** Outer loop starts at $i = n/2$ to $n$ ($\mathcal{O}(n)$ steps); inner loops multiply indices by 2 ($j = 2j, k = 2k$) ($\mathcal{O}(\log n)$ steps each).
* **Asymptotic Bound:** $\mathcal{O}(n \log^2 n)$ time, $\mathcal{O}(1)$ auxiliary space.
* **Sample Test:** Input: `4` $\rightarrow$ Count: `30` | Input: `10` $\rightarrow$ Count: `212`.

#### 5. Digit Reversal Complexity
* **Objective:** Count operations for extracting and accumulating digits base 10: `remainder = n % 10; rev = rev * 10 + remainder; n /= 10`.
* **Asymptotic Bound:** $\mathcal{O}(\log_{10} n)$ time, $\mathcal{O}(1)$ auxiliary space.
* **Sample Test:** Input: `12` $\rightarrow$ Count: `11` | Input: `1234` $\rightarrow$ Count: `19`.

### Module 2: Greedy Strategy & Sorting Optimization

The **Greedy Paradigm** constructs a global optimum by sequentially selecting locally optimal choices without backtracking.

#### 6. Indian Currency Change (Minimum Notes/Coins)
* **Problem:** Given value $V$, determine the minimum number of notes/coins required from the infinite supply canonical set $\{1000, 500, 100, 50, 20, 10, 5, 2, 1\}$.
* **Strategy:** Iterate from highest denomination downwards, greedily subtracting maximum integer multiples: `count += V / denom[i]; V %= denom[i];`.
* **Complexity:** $\mathcal{O}(M)$ time where $M = 9$, $\mathcal{O}(1)$ space.
* **Sample Test:** Input: `49` $\rightarrow$ Output: `5` ($1 \times 20 + 2 \times 10 + 1 \times 5 + 2 \times 2$).

#### 7. Assign Cookies (Content Children Maximization)
* **Problem:** Match children greed factors $g[i]$ with available cookie sizes $s[j]$ such that maximum children receive $s[j] \ge g[i]$.
* **Strategy:** Sort both arrays using C standard library `qsort()`, then advance cookie pointer $j$ until cookie satisfies child $i$.
* **Complexity:** $\mathcal{O}(n \log n + m \log m)$ time, $\mathcal{O}(1)$ space.

#### 8. Calorie Burn Minimization (Burger Running Distance)
* **Problem:** Eating the $i$-th burger with $c$ calories requires running $3^i \cdot c$ km. Find the minimum total distance to burn all calories.
* **Strategy:** Sort calories in **descending order** so that the highest calorie burgers are multiplied by the smallest powers of 3 ($3^0, 3^1, \dots$).
* **Complexity:** $\mathcal{O}(n \log n)$ time, $\mathcal{O}(1)$ space.
* **Sample Test:** Input: `3` burgers `[1, 3, 2]` $\rightarrow$ Output: `18` km ($3^0 \cdot 3 + 3^1 \cdot 2 + 3^2 \cdot 1 = 3 + 6 + 9 = 18$).

#### 9. Maximize Array Sum with Indices
* **Problem:** Given $N$ integers, maximize $\sum_{i=0}^{N-1} (arr[i] \cdot i)$.
* **Strategy:** Sort the array in ascending order; smallest numbers receive smaller index multipliers, largest numbers receive largest index multipliers.
* **Complexity:** $\mathcal{O}(n \log n)$ time, $\mathcal{O}(1)$ space.
* **Sample Test:** Input: `[2, 5, 3, 4, 0]` $\rightarrow$ Sorted: `[0, 2, 3, 4, 5]` $\rightarrow$ Output: `40`.

#### 10. Minimum Scalar Product of Two Arrays
* **Problem:** Rearrange two arrays $A$ and $B$ of size $N$ such that $\sum (A[i] \cdot B[i])$ is minimized.
* **Strategy:** Sort array $A$ ascending and array $B$ descending. Pair the largest element of one with the smallest element of the other.
* **Complexity:** $\mathcal{O}(n \log n)$ time, $\mathcal{O}(1)$ space.

### Module 3: Divide and Conquer Algorithms

#### 11. Count Zeroes in a Binary Sorted Array
* **Problem:** Given an array of 1s followed strictly by 0s, count the total number of 0s in sublinear time.
* **Strategy:** Binary divide-and-conquer: If `a[mid] == 0`, all elements to the right are also 0 ($high - mid + 1$), and recurse on the left half `[low, mid-1]`.
* **Complexity:** $\mathcal{O}(\log n)$ time, $\mathcal{O}(\log n)$ call stack space.

#### 12. Recursive Majority Element
* **Problem:** Find the majority element appearing $> \lfloor n/2 \rfloor$ times.
* **Strategy:** Divide array into left and right halves. Find majority of each half. If they disagree, run a linear count in the range to determine the winner.
* **Recurrence:** $T(n) = 2T(n/2) + 2n \implies \mathcal{O}(n \log n)$.

#### 13. Floor Value in a Sorted Array
* **Problem:** Find the greatest element in a sorted array that is $\le x$.
* **Strategy:** Modified Binary Search: If `a[mid] == x`, return `a[mid]`. If `a[mid] > x`, search left half. If `a[mid] < x`, search right half; if right half returns `-1`, return `a[mid]`.
* **Complexity:** $\mathcal{O}(\log n)$ time, $\mathcal{O}(1)$ auxiliary space.

#### 14. Pair with Target Sum ($x$) in Sorted Array
* **Problem:** Determine if two elements exist such that $A[i] + A[j] = x$.
* **Strategy:** For every element $A[i]$, recursively binary search the sub-array for target complement $x - A[i]$.
* **Complexity:** $\mathcal{O}(n \log n)$ time.

#### 15. In-Place Quick Sort Implementation
* **Problem:** Implement standard recursive Quick Sort.
* **Strategy:** Select middle pivot `pivot = a[(low + high)/2]`. Partition with two inward pointers `i` and `j`, swap inverted elements, and recurse on `(low, j)` and `(i, high)`.
* **Complexity:** $\mathcal{O}(n \log n)$ average, $\mathcal{O}(n^2)$ worst case.

### Module 4: Dynamic Programming

Dynamic programming solves complex multi-stage problems by combining solutions to overlapping subproblems.

#### 16. Playing with Numbers (1s and 3s Representation)
* **Problem:** Count the number of ordered ways to form integer $n$ using only additions of 1 and 3.
* **Recurrence Relation:**
  $$\text{Ways}(n) = \text{Ways}(n-1) + \text{Ways}(n-3)$$
* **Space-Optimized Tabulation:** Implemented with 3 rolling variables `a, b, c` instead of full array, handling large combinations via `unsigned long long`.
* **Complexity:** $\mathcal{O}(n)$ time, $\mathcal{O}(1)$ space.
* **Sample Test:** Input: `6` $\rightarrow$ Output: `6` | Input: `100` $\rightarrow$ Output: `24382819596721629`.

#### 17. Chessboard Maximum Monetary Path
* **Problem:** Start at $(0,0)$ on an $N \times N$ monetary grid and reach $(N-1, N-1)$ moving strictly right or down while maximizing the collected sum.
* **DP Recurrence:**
  $$DP[i][j] = \text{val}[i][j] + \max(DP[i-1][j], DP[i][j-1])$$
* **Complexity:** $\mathcal{O}(n^2)$ time, $\mathcal{O}(n^2)$ auxiliary space.

#### 18. Longest Common Subsequence (LCS)
* **Problem:** Find the maximum length of common subsequences between strings $s_1$ and $s_2$.
* **DP Recurrence:**
  $$DP[i][j] = \begin{cases} DP[i-1][j-1] + 1 & \text{if } s_1[i-1] == s_2[j-1] \\ \max(DP[i-1][j], DP[i][j-1]) & \text{otherwise} \end{cases}$$
* **Complexity:** $\mathcal{O}(|s_1| \cdot |s_2|)$ time and space.

#### 19. Longest Non-decreasing Subsequence
* **Problem:** Given sequence $A$, find length of the longest non-decreasing subsequence.
* **Recurrence:** $DP[i] = 1 + \max(\{DP[j] \mid 0 \le j < i \land A[j] \le A[i]\} \cup \{0\})$.
* **Complexity:** $\mathcal{O}(n^2)$ time, $\mathcal{O}(n)$ auxiliary space.

### Module 5: Linear-Time Optimizations & Two Pointers

#### 20. Find Duplicate in Read-Only Array
* **Problem:** Array of size $n$ contains integers in range $[1, n]$ with one repeated element.
* **Strategy:** Direct frequency map / bucket counter `count[n+1]`.
* **Complexity:** $\mathcal{O}(n)$ time, $\mathcal{O}(n)$ space.

#### 21. Intersection of Two Sorted Arrays
* **Problem:** Given two sorted arrays $A$ and $B$, print all common elements in sorted order.
* **Strategy:** Initialize pointers $i = 0, j = 0$.
  * If $A[i] == B[j]$: Print element, increment both $i++$ and $j++$.
  * Else if $A[i] < B[j]$: Increment $i++$.
  * Else: Increment $j++$.
* **Complexity:** $\mathcal{O}(n_1 + n_2)$ linear time, $\mathcal{O}(1)$ auxiliary space.

#### 22. Pair with Given Difference ($A[j] - A[i] = k$)
* **Problem:** In a sorted array, determine if there exists a pair $(i, j)$ with $i \ne j$ such that $A[j] - A[i] = k$.
* **Strategy:** Two forward-moving pointers $i = 0, j = 1$:
  * Calculate `diff = A[j] - A[i]`.
  * If `diff == k` and $i \ne j$: Return 1.
  * If `diff < k`: Increment $j++$.
  * If `diff > k`: Increment $i++$.
  * If $i == j$: Advance $j++$.
* **Complexity:** $\mathcal{O}(n)$ time, $\mathcal{O}(1)$ auxiliary space.
