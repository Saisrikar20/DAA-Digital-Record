## 📑 Detailed Module Breakdown

### 🔹 Module 1: Empirical Analysis & The Counter Method
> [📄 Direct PDF: Module-1-Counter-Method.pdf](./Module-1-Counter-Method.pdf) (Pages 1–15)

The **Counter Method** measures the exact computational work performed by an algorithm by embedding increments (`count++`) at every basic instruction, condition check, and loop body.
* **While-Loop Accumulator ($s \le n$):** Empirical step count for conditional accumulator patterns (Triangular number boundary $\implies \mathcal{O}(\sqrt{n})$).
* **Branching & Nested Loops:** Step count analysis on branched execution paths with early break statements (Formula: $5n + 2 \implies \mathcal{O}(n)$).
* **Divisor & Factor Counting:** Step tracking across exhaustive integer factor search (Formula: $2n + \text{factors} + 1 \implies \mathcal{O}(n)$).
* **Multi-Nested Logarithmic Loops:** Outer loop scaled by $n/2$, inner loops scaled multiplicatively by $2$ (Formula $\implies \mathcal{O}(n \log^2 n)$).
* **Digit Extraction & Reversal:** Step count on iterative base-10 digit decomposition (Formula: $4d + 3 \implies \mathcal{O}(\log_{10} n)$).

---

### 🔹 Module 2: Greedy Strategy & Sorting Optimization
> [📄 Direct PDF: Module-2-Greedy-Technique.pdf](./Module-2-Greedy-Technique.pdf) (Pages 1–15)

The **Greedy Paradigm** constructs a global optimum by sequentially selecting locally optimal choices without backtracking.
* **Indian Currency Change:** Minimum notes/coins using canonical set $\{1000, 500, 100, 50, 20, 10, 5, 2, 1\}$ (Iterative greedy modulo division $\implies \mathcal{O}(M)$).
* **Assign Cookies:** Match children greed factors $g[i]$ with cookie sizes $s[j]$ to maximize content children (Dual `qsort` + two-pointer advance $\implies \mathcal{O}(n \log n + m \log m)$).
* **Burger Calorie Burn Minimization:** Minimizing total running distance $\sum (3^i \cdot c_i)$ (Descending `qsort` greedily pairs largest calories with smallest powers $\implies \mathcal{O}(n \log n)$).
* **Maximize Array Sum with Indices:** Maximizing $\sum (arr[i] \cdot i)$ (Ascending `qsort` pairs largest elements with largest multipliers $\implies \mathcal{O}(n \log n)$).
* **Minimum Product Sum of Two Arrays:** Sorting array $A$ ascending and array $B$ descending to minimize pairwise scalar products (Dual `qsort` $\implies \mathcal{O}(n \log n)$).

---

### 🔹 Module 3: Divide and Conquer Algorithms
> [📄 Direct PDF: Module-3-Divide-and-Conquer.pdf](./Module-3-Divide-and-Conquer.pdf) (Pages 1–15)

Breaking problems down into independent subproblems, solving recursively, and combining solutions.
* **Count Zeroes in Binary Array:** Modified binary search boundary detection; if $A[mid] == 0$, right elements are all 0 ($high - mid + 1$) + search left ($\mathcal{O}(\log n)$).
* **Recursive Majority Element:** Divide array into left/right halves, find sub-majorities, and resolve discrepancies via frequency counting (Recurrence: $T(n) = 2T(n/2) + 2n \implies \mathcal{O}(n \log n)$).
* **Floor Value in Sorted Array:** Modified binary search identifying the largest element $\le x$ ($\mathcal{O}(\log n)$).
* **Pair with Target Sum ($x$):** Linear outer loop with recursive binary search for complement ($x - A[i]$) ($\mathcal{O}(n \log n)$).
* **In-Place Quick Sort:** Divide-and-conquer in-place recursive partitioning using central pivot selection and bidirectional inward pointers ($\mathcal{O}(n \log n)$ avg).

---

### 🔹 Module 4: Dynamic Programming
> [📄 Direct PDF: Module-4-Dynamic-Programming.pdf](./Module-4-Dynamic-Programming.pdf) (Pages 1–11)

Overcoming overlapping subproblems through optimal substructure caching and bottom-up tabulation.
* **Playing with Numbers (1s and 3s Representation):** Ordered compositions using numbers 1 and 3 ($DP[i] = DP[i-1] + DP[i-3]$, space-optimized rolling variables in $\mathcal{O}(n)$ time, $\mathcal{O}(1)$ space).
* **Chessboard Maximum Monetary Path:** Optimal monetary reward traversing $(0,0)$ to $(n-1, n-1)$ moving strictly right or down ($DP[i][j] = \text{val} + \max(DP[i-1][j], DP[i][j-1])$ in $\mathcal{O}(n^2)$ time/space).
* **Longest Common Subsequence (LCS):** 2D dynamic programming grid finding longest common non-contiguous character sequence between two strings ($\mathcal{O}(|s_1| \cdot |s_2|)$).
* **Longest Non-decreasing Subsequence:** Dynamic programming tracking longest non-decreasing sequence length ($DP[i] = 1 + \max(DP[j])$ for $j < i, A[j] \le A[i]$ in $\mathcal{O}(n^2)$).

---

### 🔹 Module 5: Linear-Time Optimizations & Two Pointers
> [📄 Direct PDF: Module-5-Two-Pointers.pdf](./Module-5-Two-Pointers.pdf) (Pages 1–18)

Dual-pointer strategies and complexity comparisons transforming quadratic $\mathcal{O}(n^2)$ algorithms into linear $\mathcal{O}(n)$ solutions.
* **Find Duplicate in Read-Only Array:** Comparing naive quadratic search $\mathcal{O}(n^2)$ vs frequency counting $\mathcal{O}(n)$.
* **Intersection of Two Sorted Arrays:** Comparing nested loop comparison $\mathcal{O}(m \cdot n)$ vs dual advancing pointers in sorted arrays $\mathcal{O}(m + n)$ time with $\mathcal{O}(1)$ space.
* **Pair with Given Difference ($A[j] - A[i] = k$):** Comparing exhaustive pairs $\mathcal{O}(n^2)$ vs two forward-moving pointer scan $\mathcal{O}(n)$ time and $\mathcal{O}(1)$ space.
